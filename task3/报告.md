## 题2：最小二乘法拟合（二元非线性函数）

**题目**：用 PyTorch 自动求导 + 梯度下降拟合题目给定的二元非线性函数

```text
y = 2x1² + 1.5x1x2 + 3sin(x1) + 0.5cos(2x2) + e^(-0.5x1) + 0.8x2 + 2026 + 噪声(-3 ~ 3)
```

要求拟合的参数形式包含 7 个未知量：

```text
y = a1x1² + a2x1x2 + a3sin(x1) + a4cos(2x2) + e^(a5x1) + a6x2 + b
```

**实现**（`q2_least_squares_2d.py`）：

1. 在 x1、x2 ∈ [-3, 3] 内均匀采样 2000 个点，噪声取 [-3, 3] 均匀随机数
2. 把 `a1..a6` 与 `b` 设成 `requires_grad=True` 的张量，交给自动求导
3. 前向传播按上式构造 `y_pred`，损失用 MSE
4. 每轮 `loss.backward()` 后**手写梯度下降**更新参数（不调用 optimizer）：
   `a -= lr * a.grad`、`b -= lr * b.grad`，随后 `grad.zero_()`
5. 学习率 0.01、迭代 3000 次

**关键细节：b 的初始化**

`b` 的真实值约 2026，比其它项（约 ±40）大两个数量级。实测若把 `b` 从 0 初始化，
梯度会因量级悬殊而爆炸，损失在第 500 轮内就变成 `NaN`；
因此这里用**样本均值**初始化 `b`，训练才能稳定收敛。这是本题最容易被忽略的坑。

**结果**：

| 参数 | 拟合值 | 真实值 | 误差 |
|------|--------|--------|------|
| a1 | 2.0125 | 2.0 | 0.0125 |
| a2 | 1.5099 | 1.5 | 0.0099 |
| a3 | 2.9554 | 3.0 | 0.0446 |
| a4 | 0.4352 | 0.5 | 0.0648 |
| a5 | -0.4916 | -0.5 | 0.0084 |
| a6 | 0.8250 | 0.8 | 0.0250 |
| b | 2026.0264 | 2026.0 | 0.0264 |

| 指标 | 数值 |
|------|------|
| 决定系数 R² | **0.948643** |
| 最终 MSE | 3.0736 |

7 个参数的误差都在 0.07 以内。R² 约 0.949，与题目示例图标注的 0.9486 一致——
这是**噪声 ±3 相对函数值波动（标准差约 7.7）偏大**导致的正常水平，并非拟合不充分。

## 题3：MLP 识别 MNIST

**数据**：题目提供的 parquet 文件，共 60000 张 28x28 灰度手写数字。
用 pandas 读取后，把每行的 PNG 字节流用 Pillow 解码成 numpy 数组，
像素值归一化到 [0,1]，前 50000 张训练、后 10000 张测试。

**模型结构**：

```text
784 (28x28 展平)
  -> Linear 256 + ReLU + Dropout(0.2)
  -> Linear 128 + ReLU + Dropout(0.2)
  -> Linear 10 (对应 0-9 十个类别)
```

**训练配置**：交叉熵损失、Adam 优化器（lr=1e-3）、
batch=128、20 个 epoch，CPU 上约 30 秒完成。

**结果**：

| 指标 | 数值 |
|------|------|
| 最终训练准确度 | 99.37% |
| 最终测试准确度 | **98.05%** |

训练损失持续下降，训练准确度和测试准确度同步上升，
两者的差距保持在 1.3 个百分点左右，没有出现明显过拟合
（Dropout 起到了正则化作用）。

![训练曲线](outputs/q3_curves.png)

从测试集抽取样本可视化，绿色标题表示预测正确、红色表示错误。
绝大多数样本预测正确，偶发的错误集中在外形相似的数字对上
（如 4/9、3/5）。
