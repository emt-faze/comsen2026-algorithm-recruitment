## 题2：最小二乘法拟合

**题目**：用 PyTorch 自动求导 + 梯度下降拟合 `y = 3.5x + 4.2 + noise`
（noise 为 [-0.5, 0.5] 均匀随机数），学习率 0.01、迭代 1000 次、
初始权重和偏置均为 0。

**实现**：把 `w`、`b` 设成 `requires_grad=True` 的张量，
前向传播计算 `y_pred = w*x + b`，损失用 MSE；
每轮 `loss.backward()` 自动算出梯度后手动更新
`w -= lr * w.grad`、`b -= lr * b.grad`（即最朴素的梯度下降）。

**结果**：

| 指标 | 数值 |
|------|------|
| 拟合权重 w | **3.4916**（真实值 3.5） |
| 拟合偏置 b | **4.2158**（真实值 4.2） |
| 决定系数 R² | **0.999799** |

w 和 b 都非常接近真实值，R² 接近 1，说明 1000 次迭代已经充分收敛。
左图为不含噪声的原函数，右图为带噪声数据点和拟合直线：

## 题3：MLP 识别 MNIST

**数据**：题目提供的 parquet 文件，共 60000 张 28x28 灰度手写数字。
用 pandas 读取后，把每行的 PNG 字节流用 Pillow 解码成 numpy 数组，
像素值归一化到 [0,1]，前 50000 张训练、后 10000 张测试。

**模型结构**：

```text
784 (28x28 展平)
  -> Linear 256 + ReLU + Dropout(0.2)
  -> Linear 128 + ReLU + Dropout(0.2)
  -> Linear 10 (对应 0-9 十个类别)
```

**训练配置**：交叉熵损失、Adam 优化器（lr=1e-3）、
batch=128、20 个 epoch，CPU 上约 30 秒完成。

**结果**：

| 指标 | 数值 |
|------|------|
| 最终训练准确度 | 99.37% |
| 最终测试准确度 | **98.05%** |

训练损失持续下降，训练准确度和测试准确度同步上升，
两者的差距保持在 1.3 个百分点左右，没有出现明显过拟合
（Dropout 起到了正则化作用）。

![训练曲线](outputs/q3_curves.png)

绝大多数样本预测正确，偶发的错误集中在外形相似的数字对上
