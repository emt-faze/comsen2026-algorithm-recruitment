# task3 题一：深度学习基础概念的理解

以下是我学习过程中整理的概念笔记，尽量用自己的话把每个概念讲清楚。

## 1. 神经网络基础

**神经元 / 感知机**
神经元是神经网络的最小单元。它接收若干输入，每个输入乘上一个权重，加上一个偏置，再经过激活函数输出结果。感知机是最早的神经元模型，只能处理线性问题；多层神经元组合起来才能拟合复杂的非线性关系。

**权重 & 偏置**
权重决定"每个输入有多重要"，偏置相当于一个可调节的门槛。训练神经网络的本质，就是不断调整权重和偏置，让输出越来越接近正确答案。

**激活函数**
给网络引入非线性的函数，比如 ReLU、Sigmoid、Tanh。如果没有激活函数，无论叠多少层，整个网络等价于一次线性变换，连简单的曲线都拟合不了。

**前向传播**
数据从输入层一路乘权重、加偏置、过激活函数，最后到达输出层得到预测值的过程。

**隐藏层 & 输出层**
输入层和输出层之间的层叫隐藏层，负责提取特征；输出层负责给出最终结果，比如 10 个类别各自的分数。隐藏层越多，网络表达能力越强，但也越难训练。

**全连接层**
上一层每个神经元都连接到下一层每个神经元的层。MLP（多层感知机）就是由全连接层堆起来的，MNIST 任务里把手写图片展平成 784 个像素后接全连接层就是这个用法。

## 2. 训练与优化

**损失函数**
量化"预测值和真实值差多少"的函数。回归常用 MSE（均方误差），分类常用交叉熵。训练的目标就是让损失尽可能小。

**梯度下降**
一种找损失最小值的方法：计算损失对每个参数的梯度（当前位置的"坡度"），然后朝坡度下降的方向更新参数。学习率决定每一步走多远。

**反向传播（链式法则）**
高效计算梯度的算法。前向传播算出损失后，从输出层往输入层逐层运用链式法则，把误差"分摊"回每个权重和偏置。PyTorch 的 `loss.backward()` 就是自动完成这件事。

**学习率**
参数每一步更新的步长。太大会来回震荡甚至发散，太小则收敛很慢。题目里最小二乘拟合用的 0.01 就是一个适中的值。

**优化器**
决定"怎么用梯度更新参数"的算法。SGD 是最朴素的；Adam 会为每个参数自适应调整步长，收敛通常更快，我在 MNIST 任务里用的就是 Adam。

**混合精度训练**
训练时用 FP16（半精度）代替 FP32（单精度）做部分计算，能省显存、提速，再配合少量 FP32 运算保证数值稳定。适合大模型，我的小任务用不上。

**Epoch、Batch、Iteration**
一个 Epoch 是整个训练集完整过一遍；Batch 是一次前向+反向所用的样本子集；Iteration 是一次参数更新。60000 个样本、batch=128 时，一个 Epoch 大约 469 个 iteration。

## 3. 关键技巧与调参

**过拟合 & 欠拟合**
过拟合是模型把训练集"背"下来了，训练准确率很高但测试集表现差；欠拟合是模型太弱，连训练集都学不好。判断方法就是对比训练集和测试集的表现差距。

**正则化（L1、L2、Dropout）**
防止过拟合的手段。L1 在损失里加权重绝对值之和，会产出稀疏权重；L2 加权重平方和，让权重整体变小、模型更平滑；Dropout 训练时随机丢弃一部分神经元，逼网络不依赖个别神经元。我的 MLP 里用了 Dropout(0.2)。

**批归一化（Batch Normalization）**
对每一层的输入按 batch 做标准化，让数值分布更稳定，训练更快更平稳。

**训练集 / 验证集 / 测试集**
训练集用来学参数；验证集用来调超参数、判断该训练多久；测试集只在最后评估，不能参与任何训练决策。MNIST 60000 张里我留了 10000 张做测试集。

## 4. 基础工具与概念

**Tensor / 张量**
PyTorch 里的基本数据结构，可以理解为多维数组（标量、向量、矩阵、更高维），并且支持 GPU 加速和自动求导。

**自动求导（Autograd）**
PyTorch 会记录对 Tensor 的每一步运算，调用 `backward()` 时自动按链式法则算出梯度，不用手写求导公式。题目二的最小二乘拟合就是靠它完成的。

**GPU 与 CPU 区别**
CPU 核心少但单核强，适合逻辑复杂的任务；GPU 有几千个小核心，擅长并行做大量相同的矩阵乘法，而神经网络训练正好全是矩阵运算，所以大模型都用 GPU 训练。我的模型小，CPU 就够用。
